# Starter task outcomes

This log tracks first-time contributor outcomes for curated `good first issue`
queues, following [#325](https://github.com/google/elephant-goldfish-model/issues/325)
and [#332](https://github.com/google/elephant-goldfish-model/issues/332).

## Starter queue standards

- **Task scope**: Each `good first issue` specifies a clear scope, observable
  acceptance criteria, and a validation command.
- **Response target**: Maintainers aim to respond to first-time contributors
  within two business days.
- **Review cadence**: Review outcomes one month after publishing a starter
  queue and record the results below.

## Review template

Copy this block for each monthly review:

```markdown
### Review: <YYYY-MM-DD> (<queue or tracking issue>)

- **Review period**: <YYYY-MM-DD> to <YYYY-MM-DD>
- **Starter queue**: <#issue, ...>
- **Time to first response**: <median and range vs. two-business-day target>
- **Tasks completed**: <count of starter tasks completed by first-time contributors>
- **Data gaps**: <missing timestamps, unrecorded claims, or external factors>
- **Adjustments**: <changes to starter task scoping, docs, or triage>
```

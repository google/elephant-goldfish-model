title: Diagnose a bug
description: Investigate a bug independently, then compare evidence before choosing a fix.

Start with the observed symptom, reproduction steps, and expected behavior. A fresh reviewer investigates the evidence without seeing the initial theory. Compare both diagnoses and record what would rule out each candidate before deciding what to fix.

## Start with the method

Read the [repository setup guide](https://github.com/google/elephant-goldfish-model/blob/main/docs/getting_started.md). It introduces the conversational approach and links to the foundational article. You can try the method before installing the plugin.

## Choose an application

The plugin runs inside a supported AI application. [Install EGM](/install) in your application before your first project.

Installing EGM does not require you to write software. Review workflows require an application that can run isolated subagents. Cloud support remains partial. Check the installation guide for the current limits.

## Start with a software idea

Describe the problem, who it affects, and what you know. For example:

```text
/egm-brainstorm
Help students book a shared study space.
Help me explore who needs access, how bookings work,
and what happens when two requests overlap.
```

The assistant asks questions and writes a short brief. Read the brief before you continue to [drafting and review](/workflow).

## Review another type of document

Save the document as a file. Use [Custom review](/skills/egm-review-loop) to choose reviewers and standards for your task.

```text
/egm-review-loop
Review study-space-plan.md.
Help me choose reviewers and standards
for the opening schedule and responsibilities.
```

Check the review settings. Check the findings before you change the plan.
